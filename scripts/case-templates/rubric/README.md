# Кейс «__CASE_SLUG__» (режим rubric: артефакт-документ по рубрике)

Каркас кейса, где агент превращает неструктурированный вход (стенограмма,
переписка, набор заметок…) в **markdown-документ** (BR, отчёт, спецификацию),
а бенчмарк скорит его по рубрике: 30% — обязательные разделы, 70% —
обязательные факты с весами. Образец боевого кейса: `cases/analytics-meeting`.

## Файлы кейса

| Файл | Что это |
|------|---------|
| *(добавьте входные данные)* | Например `input-ru.md` — то, что читает агент. |
| `rubric.json` | Рубрика оценки: обязательные разделы + факты с ключевыми словами и весами. |
| `expected-output.md` | Эталонный («золотой») артефакт — как должен выглядеть результат. |
| `benchmark.py` | Скоринг 0–100, таблица покрытия, список пропущенных фактов. |

## Вход

ЗАПОЛНИТЕ: положите входные данные кейса рядом (например,
`cases/__CASE_SLUG__/input-ru.md`) и опишите здесь, что это и откуда.

## Как прогнать агента

ЗАПОЛНИТЕ под ваш кейс; типовой ход (см. `cases/analytics-meeting/README.md`):

1. Поднимите нужные моки: `python3 mocks/run_all.py`.
2. Подключите MCP-серверы (конфиги в `mcp/configs/`).
3. Запустите агента с навыком трека (`tracks/*/skill.md`), подав входные
   данные кейса; агент пишет артефакт, например `artifact-agent.md`.

## Бенчмарк

```bash
python3 cases/__CASE_SLUG__/benchmark.py artifact-agent.md            # отчёт
python3 cases/__CASE_SLUG__/benchmark.py artifact-agent.md --score-only  # число для CI
python3 cases/__CASE_SLUG__/benchmark.py --self-test   # эталон >= 95, сейчас зелёный
```

Если после правок рубрики или эталона `--self-test` падает — сначала чините
их согласованность, потом гоняйте агента.

## Ручной бейслайн (для демо «агент vs человек»)

1. Один участник **до** запуска агента пишет артефакт руками по тем же входным
   данным, с таймером.
   ⚠️ Спойлер: `benchmark.py` печатает эталонную таблицу фактов — «ручной»
   участник не должен запускать бенчмарк и открывать `expected-output.md` /
   `rubric.json`, пока не закончит, иначе бейслайн испорчен подсказками.
2. Запишите: время и скор человека, время и скор агента.
3. Табличка «человек: N минут / X баллов, агент: M минут / Y баллов» — в демо.
