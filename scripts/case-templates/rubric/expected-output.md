# Эталонный артефакт кейса «__CASE_SLUG__» (ПЛЕЙСХОЛДЕР)

> ЗАМЕНИТЕ этот файл «золотым» ответом по вашему кейсу: как должен выглядеть
> идеальный артефакт (BR, отчёт, спецификация…). Сейчас здесь минимальная
> заглушка, согласованная с `rubric.json`, чтобы `--self-test` был зелёным
> с нулевой секунды. Правьте эталон и рубрику вместе.

## Цель

Плейсхолдер-факт-1: здесь должна быть цель / главный вывод по кейсу.

## Требования

- Плейсхолдер-факт-2: первое обязательное требование из входных данных.

## Открытые вопросы

- Плейсхолдер-факт-3: вопрос, который во входных данных остался нерешённым.
