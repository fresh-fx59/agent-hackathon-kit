# Кейс «__CASE_SLUG__» (режим findings: поиск проблем в коде)

Каркас кейса, где агент анализирует код и выдаёт **`findings.json`** — список
проблем (файл, строка, категория, серьёзность, описание, как чинить), а
бенчмарк сравнивает его с эталоном и считает **precision / recall / F1**
(совпадение = тот же файл по basename + та же категория + строка ±5).
Образец боевого кейса: `cases/dev-techdebt`.

## Файлы кейса

| Файл | Что это |
|------|---------|
| *(добавьте код для анализа)* | Например каталог `src/` с намеренно заложенными проблемами. |
| `expected-findings.json` | Эталонный список проблем («золотой» ответ). |
| `benchmark.py` | Скоринг: precision / recall / F1, таблица по категориям, списки missed / extra. |

Категории: `security | bug | smell | duplication | dead-code | style`.

## Вход

ЗАПОЛНИТЕ: положите анализируемый код в `cases/__CASE_SLUG__/src/` (или
укажите реальный репозиторий) и опишите здесь, что это.

## Как прогнать агента

ЗАПОЛНИТЕ под ваш кейс; типовой ход (см. `cases/dev-techdebt/README.md`):

1. При необходимости поднимите моки: `python3 mocks/run_all.py`.
2. Запустите агента с навыком трека (`tracks/development/skill.md`), подав
   код кейса; агент пишет `findings.json` — JSON-массив объектов вида
   `{"file", "line", "category", "severity", "description", "fix_hint"}`.

## Бенчмарк

```bash
python3 cases/__CASE_SLUG__/benchmark.py findings.json               # полный отчёт
python3 cases/__CASE_SLUG__/benchmark.py findings.json --score-only  # число F1 для CI
python3 cases/__CASE_SLUG__/benchmark.py --self-test  # эталон против себя, F1 = 1.0
```

Список `EXTRA` — не всегда ошибка агента: находка может быть реальной, но
отсутствовать в эталоне. Проверяйте руками и пополняйте эталон.

## Ручной бейслайн (для демо «агент vs человек»)

1. Один участник **до** запуска агента делает ревью кода руками и пишет свой
   `findings-manual.json`, с таймером.
   ⚠️ Спойлер: бенчмарк печатает эталонные находки — «ручной» участник не
   должен запускать `benchmark.py` и открывать `expected-findings.json`,
   пока не закончит, иначе бейслайн испорчен подсказками.
2. Запишите: время и F1 человека, время и F1 агента.
3. Табличка «человек: N минут / F1 X, агент: M минут / F1 Y» — в демо.
