# Workflow: Sherlock — разбор инцидента по логам (offline)

Режим «разработчик/тестировщик просит разобрать». Запускается словами человека,
никаких команд запоминать не нужно.

```mermaid
flowchart TD
    A["Инженер: «упал сервис, логи вот тут»"] --> B{Навык сработал?}
    B -->|нет| B1["Ответ обычной модели<br/>риск: «ничего критичного»"]
    B -->|да| C["Шаг 0. Читаем подтверждённые<br/>карточки паттернов knowledge/"]
    C --> D{Совпал известный паттерн?}
    D -->|да| D1["Быстрый путь: проверить сигнатуру,<br/>подтвердить уликами"]
    D -->|нет| E["Шаг 1. Карта корпуса<br/>файлы, размеры, плотность ошибок, .gz"]
    E --> F["Шаг 1б. Дисциплина покрытия<br/>список всех файлов, каждый закрыть явно"]
    F --> G["Шаг 2. Сужение<br/>якорь = самая ранняя строка, окно вокруг"]
    G --> H["Шаг 3. Корреляция между источниками<br/>id переименовывается → падать на время"]
    H --> I["Шаг 4. Гипотезы и их отбраковка<br/>что бы опровергло? приманки"]
    I --> J["Шаг 5. Код, если доступен<br/>rg/ast-grep, игнорируя комментарии"]
    J --> K["Шаг 6. Проверка улик<br/>перечитать каждую файл:строка"]
    D1 --> K
    K --> L["Отчёт: причина, цепочка, улики,<br/>действия, правка, «чего я не знаю»"]
    L --> M{Паттерн стоит запомнить?}
    M -->|да| N["Предложить карточку<br/>человек подтверждает / правит / отклоняет"]
    M -->|нет| O["«Новых паттернов нет»<br/>сказать явно, не молчать"]
    N --> P["knowledge/patterns/*.md<br/>в git, едет вместе с навыком"]

    style B1 fill:#7a1f1f,color:#fff
    style L fill:#1f4d2e,color:#fff
    style P fill:#1f3a5f,color:#fff
```

**Почему шаг 6 обязателен.** Выдуманная улика дороже отсутствующей: она стоит
инженеру часа работы. Утверждение без подтверждённой строки удаляется из отчёта.

**Почему шаг 1б — главный.** Замерено: на одном корпусе и одной модели результат
менялся 100 % → 73 % → 18 % только из-за того, какие файлы агент открыл. Худший
прогон был самым аккуратным в вычислениях — он просто не открыл 12 файлов из 28.

**Где человек в контуре.** Единственная точка — подтверждение карточки. Всё
остальное агент делает сам; карточка без подтверждения не сохраняется никогда.
