## Что это значит

Автоматизированный подбор пароля к SSH. Каждая попытка — отдельное TCP-соединение
с новым исходящим портом, поэтому `MaxAuthTries` внутри одного соединения ничего
не ограничивает: счётчик сбрасывается на каждом коннекте.

## Корневая причина

На хосте открыт SSH на публичном интерфейсе **и разрешена парольная
аутентификация**. Всё остальное (роботы, ботнеты, сканеры) — это фон интернета,
а не причина. Причина всегда на стороне конфигурации хоста.

## Что делать

1. `PasswordAuthentication no` — только ключи. Это закрывает класс целиком.
2. `PermitRootLogin prohibit-password`.
3. fail2ban / `pam_faillock` — блокировка по источнику, а не по соединению.
4. Ограничить доступ к 22/tcp сетевым фильтром (VPN, allow-list) — если можно.

## Обязательная проверка на эскалацию (не пропускать)

Перебор сам по себе — шум. **Опасен он только если что-то подобралось.**
Всегда проверь в том же корпусе:

    grep -n "Accepted password\|Accepted publickey\|session opened for user" <файлы>

Успешный вход **в окне шторма или сразу после** — это компрометация, приоритет
выше самого перебора. Проверь: этот пользователь вообще должен существовать?
С какого адреса он входит обычно?

## Чем это НЕ является (ложные срабатывания)

- `reverse mapping checking getaddrinfo … POSSIBLE BREAK-IN ATTEMPT!` — **не взлом**.
  Это несовпадение PTR- и A-записи. В нашем же корпусе таких строк 85 при одном
  успешном входе. Само по себе уликой не является — см. `../REJECTED.md`.
- Одиночные `authentication failure` от одного источника — обычно человек
  ошибся паролем. Порог из `confirm_threshold` существует именно для этого.

## Улики (проверено построчно 2026-07-28)

- `OpenSSH_2k.log:2` → `Invalid user webmaster from 173.234.31.186`
- `OpenSSH_2k.log:519` → `Failed password for root from 187.141.143.180 port 33314 ssh2`
- `OpenSSH_2k.log:523` → `Failed password for root from 187.141.143.180 port 34508 ssh2`
  (тот же источник, другой порт — подтверждение «новое соединение на попытку»)
- `OpenSSH_2k.log:956` → `Accepted password for fztu from 119.137.62.142 port 49116 ssh2`
  — единственный успешный вход на 520 неудачных. Это и есть находка.

## Что карточка НЕ отменяет

Она сокращает **поиск**, а не **проверку**. Дисциплина покрытия, перечитывание
каждой цитаты по `файл:строка` и раздел «чего я не знаю» остаются обязательными.
Корпус почти никогда не состоит из одного паттерна: найдя перебор, продолжай
расследование остальных файлов и сервисов.
