# Immutable version gate development report

## Current state

Task 2 implementation and provider-free verification are complete. The direct
runner and target probe bind selected Sherlock runtime packages through an
offline immutable registry and read-only snapshot. The one valid finding from
the scoped review is repaired and the complete affected suites are green. No
provider contact or v44 runtime package change occurred.

## Interface decision

The implementation boundary is a small stdlib helper beside the benchmark
scripts. Its selector accepts only an explicit `v<number>` package-version
argument; `PrepareArgs.arm` remains an arbitrary legacy run label. The helper
verifies the Git-trusted append-only registry and copies a checked package to a
sealed snapshot before the probe or runner can invoke a contact-capable path.
