## 1. Вывод

**[PROVEN]** В Security за 1–2 июня 2021 года находятся 33 456 неуспешных входов EID4625, все с LogonType=3. Из них 33 455 используют NTLM/NtLmSsp и содержат один из 93 публичных IP; одна запись является локальной проверкой Advapi/MSV1_0 без IP. **[PROVEN]** RDP-соединения к `RDP-Tcp` подтверждены журналами Terminal Services. В пересекающемся окне их IP и время совпадают с частью отказов Security. **[INFERENCE]** RDP — обоснованный канал наблюдаемой атаки, но каждый из 33 456 отказов индивидуально с RDP-соединением не сопоставлен.

**[PROVEN]** В удержанном июньском Security нет успешного входа обычной пользовательской учётной записи: 182 EID4624 относятся к `СИСТЕМА`/LogonType5, ещё три — к `UMFD-2`/`DWM-2`/LogonType2. **[PROVEN]** В мае LSM непосредственно показывает успешный сеанс `IPSERVER\root` и его переподключения. 9 мая установлен автоматически запускаемый `3proxy tiny proxy server` под LocalSystem; событие установки содержит SID, сопоставленный с `root`. **[PROVEN]** В удержанных источниках нет Security4688, Security5156/5157, PowerShell4103/4104, событий управления учётными записями4720/4722/4724/4738/4726. Не установлены: номер порта назначения RDP, состояние NLA, содержимое паролей/стратегия spray, реальная личность майского root-оператора, процесс установки 3proxy, содержимое его конфигурации и использование, связь успешных системных Credential Manager-чтений с атакующим, дальнейшие события после удержанных окон.
