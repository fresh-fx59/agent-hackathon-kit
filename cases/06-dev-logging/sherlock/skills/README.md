# Версии навыка — какая поставляется

**Поставляется `v4.1`.** Это `v4` плюс один перенесённый из `v5` раздел —
«Если логи лежат не в файлах» (Loki/ES/`kubectl`/journald как источник, R4).
Больше ничего: ни базы знаний, ни шага 0, ни шага 7, ни `patterns.py`.
Установка — копирование одной папки в `~/.qwen/skills/log-rca`.

**`v5` — черновик self-learning, НЕ измерен.** Ноль строк в реестрах прогонов
(`eval/runs.jsonl`, `eval/bench/runs-bench.jsonl`, `eval/petstore/runs-petstore.jsonl`).
Продвигаем в поставку, только если матрица P0 покажет всё сразу:
не хуже `v4.1` на TC-01, строго лучше на TC-05 и TC-03, и на объёмном корпусе
нет ни потери отчёта, ни переполнения контекста. Пока этого нет — демо, не релиз.

**`v1`–`v3` — исторические**, оставлены как армы для A/B и воспроизводимости.
**`v2` не поставлять никогда**: измеренная регрессия (4,6 цитаты против 18,4
у линии v3, коллапс на 1 из 5 корпусов).

`v4` не трогаем: это база, относительно которой считается всё остальное.
