# Версии навыка — какая поставляется

**Продукт — `v5`**: то же расследовательское ядро плюс слои возможностей —
источники логов не в файлах (Loki/ES/`kubectl`/journald), сверка со спеками
(5б), анализ кода до файла и метода (6б), self-learning с человеческим гейтом
(0/7 + `knowledge/`), PII-маскирование и механическая проверка улик
(`tools/citecheck.py`). Установка — копирование одной папки в
`~/.qwen/skills/log-rca`.

**Проверенная поставка сегодня — `v4.1`**: то же ядро без новых слоёв (`v4`
плюс один перенесённый из `v5` раздел «Если логи лежат не в файлах»). Все
замеры сняты на ядре (армы `v3`/`v4`); **v5-специфика в замерах не гонялась**
— ноль строк в реестрах прогонов
(`eval/runs.jsonl`, `eval/bench/runs-bench.jsonl`, `eval/petstore/runs-petstore.jsonl`).
`v5` встаёт на место `v4.1`, когда матрица P0 покажет всё сразу:
строго лучше `v4.1` на TC-01 по паре файл:метод и по наличию построчного
фикса, строго лучше на TC-05 и TC-03, и на объёмном корпусе
нет ни потери отчёта, ни переполнения контекста. Пока этого нет — демо, не релиз.

**`v1`–`v3` — исторические**, оставлены как армы для A/B и воспроизводимости.
**`v2` не поставлять никогда**: измеренная регрессия (4,6 цитаты против 18,4
у линии v3, коллапс на 1 из 5 корпусов).

`v4` не трогаем: это база, относительно которой считается всё остальное.
